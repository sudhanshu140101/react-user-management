# react-user-management : 
A simple React.js project demonstrating user management with React Router. It fetches users from JSONPlaceholder API, displays a user list, and allows navigation to individual user details. Built with React + Vite + React Router.

Features : 

Display list of users with names and emails.
Click on a user to see detailed information.
Dynamic routing using react-router-dom.
Clean component structure (UserList.jsx, UserDetails.jsx).
